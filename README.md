# Cash Machine Engine

Cash Machine Engine è uno strumento interno che analizza automaticamente il web per trovare problemi reali che possono diventare business.

## Obiettivo

Ogni giorno il sistema:

- raccoglie dati da diverse fonti
- individua problemi ripetuti
- identifica competitor
- assegna uno score alle opportunità
- propone le migliori idee da sviluppare

## Fonti

- Reddit
- Product Hunt
- Hacker News
- GitHub Issues
- G2
- Capterra
- App Store
- Google Play
